# Тайный Санта — backend

Бесплатный self-hosted backend: Go API + PostgreSQL в Docker Compose. Рассчитан на запуск на домашнем компьютере во время игры.

## Возможности

- Создание комнаты с кодом и секретным токеном администратора.
- Добавление участников с отдельным личным токеном для каждого.
- Просмотр списка участников администратором.
- Однократная жеребьёвка: никто не получает самого себя.
- Каждый участник получает только имя своего получателя.
- В базе хранятся SHA-256-хеши токенов, а не сами токены.

## Запуск

Нужны Docker и Docker Compose.

1. Скопируй .env.example в .env.
2. Замени POSTGRES_PASSWORD на длинный случайный пароль.
3. Из корня репозитория запусти: docker compose up -d --build
4. Проверь сервер: curl http://localhost:8080/health

Остановка: docker compose down. Данные сохраняются в volume santa_pgdata. Для полного удаления данных: docker compose down -v.

API привязан к 127.0.0.1:8080 и доступен только с домашнего компьютера. Для удалённых участников позже понадобится HTTPS-туннель/прокси. Не публикуй порт PostgreSQL 5432 в интернет.

## API

Все защищённые запросы передают Authorization: Bearer TOKEN.

- POST /api/rooms — создать комнату. Ответ содержит code и admin_token; сохрани их, токен показывается только один раз.
- POST /api/rooms/{code}/participants — добавить участника. JSON: {"name":"Аня"}. Ответ содержит participant_token; передай его участнику лично.
- GET /api/rooms/{code}/participants — список участников (admin token).
- POST /api/rooms/{code}/draw — провести жеребьёвку (admin token), минимум два участника.
- GET /api/rooms/{code}/my-result — получить личный результат (participant token).
- GET /health — проверка состояния.

Первая версия — только API. Текущий index.html пока не подключён к нему. Потерянные токены восстановить нельзя. После жеребьёвки нельзя добавлять участников или повторно проводить её.
