# Тайный Санта — тест файлового Go-сервера

На этом этапе вместо базы данных используется обычный файл JSON Lines. Сервер написан на Go и запускается локально через Docker Compose.

## Что происходит

- При открытии сайта `index.html` отправляет `GET /visit` на `http://localhost:8080`.
- Go-сервер добавляет одну JSON-строку с временем посещения в `data/visits.jsonl`.
- `GET /logs` возвращает содержимое файла.
- `GET /health` проверяет, что сервер отвечает.

## Запуск

Нужны Docker и Docker Compose. В корне репозитория выполни:

```sh
docker compose up -d --build
```

Проверка сервера:

```sh
curl http://localhost:8080/health
```

Проверка записи:

```sh
curl http://localhost:8080/visit
```

Посмотреть файл через HTTP:

```sh
curl http://localhost:8080/logs
```

Файл хранится на хосте в `./data/visits.jsonl`, поэтому не пропадает при пересоздании контейнера. Остановка: `docker compose down`.

## Важно про тест с GitHub Pages

В `index.html` сейчас указан `http://localhost:8080`. Это означает localhost компьютера того, кто открыл сайт. Поэтому запрос с GitHub Pages сработает только у тебя на компьютере, если Go-сервер запущен там же. Для друзей этот адрес будет указывать на их собственные устройства. Когда проверим локальную связку, для доступа участников настроим HTTPS-туннель и поменяем `API_BASE` на его адрес.

Маршрут `/logs` открыт без авторизации специально для отладки и показывает весь журнал посещений. Не записывай туда личные данные и не оставляй этот маршрут публично доступным после теста.
